# Data Analytics Portfolio

This repository serves as the central portfolio for showcasing practical work and projects developed through data analytics training, technical coursework, and independent study.

Projects are maintained in separate repositories and organized by subject area.

## Current Portfolio Projects

### SQL Select Statements

A collection of 36 SQL files covering foundational and intermediate SQL querying techniques, developed through practice exercises and Skills-Based Assessments.

Topics include:

- Data retrieval and filtering
- JOIN operations and relational database relationships
- Aggregate functions and grouping
- Subqueries and conditional logic
- Data analysis and reporting using SQL

**Repository:** `sql-select-statements`

### Advanced Database Management

A separate SQL project demonstrating database management and development techniques beyond basic query construction.

Topics include:

- Database indexes
- Constraints
- Views
- Triggers
- Data auditing
- Related database management concepts

**Repository:** `sql-advanced-database-management`
